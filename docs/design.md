# 结构与职责

[返回首页](../README.md)

## 目标

自动积累可回查的执行证据，让模型沿着“定位 Run → 消息预览 → 完整消息”的路径阅读；清理由用户明确授权。Run 是唯一的经历实体，session、branch 和 message 只承担归属、隔离和定位职责。

模型上下文由 Pi 及其他专门插件管理。v2 对模型的入口限于 `find_run`、`get_message_detail`、`delete_run` 的定义及调用结果；事件订阅用于记录和后台摘要，用户界面通过命令、阅读面板和摘要进度提示提供反馈。

## 模块

| 模块 | 职责 |
| --- | --- |
| `src/index.ts` | 扩展注册、会话资源生命周期、录制失败反馈 |
| `src/recorder.ts` | 按宿主事件切分 Run，保存完整消息并关闭录制 |
| `src/store.ts`、`src/schema.ts`、`src/data.ts` | 独立 SQLite 库、格式检查、事务、写入者与恢复 |
| `src/summary.ts` | 从本轮归档构建有限证据，后台生成并校验摘要 |
| `src/archive.ts`、`src/content.ts` | 关键词检索、预览、分页读取与删除 |
| `src/tools.ts`、`src/tool-render.ts` | 模型工具、参数展示与可展开的调用卡片 |
| `src/ui.ts` | `/runs` 阅读面板 |

### 存储

v2 使用 `RUN2` 格式标识和独立数据库。格式校验先于建表或修改 journal mode，已有 v1、外来或不支持版本的库会被拒绝。库中保存 Run、完整消息、轻量事件、必要会话/分支绑定、活动写入者和删除墓碑。

消息正文只保存一份，事件引用消息并记录生命周期信息。事务与外键维护消息、事件和 Run 的一致性；WAL + FULL 同步保障已提交内容。每个会话只允许一个存活写入者；本机死亡进程的录制标记在重新挂接时释放，已提交证据保持原样，跨主机写入者保守拒绝接管。

对外短 ID 为库内递增的 `r` / `m` 编号，也支持 UUID；删除后短 ID 不复用。搜索和阅读游标签名绑定查询条件及上界，在同一扩展实例内使用。

### 录制边界与摘要

Run 从 `agent_start` 开始录制，到 `agent_settled` 停止录制。内部以 `recording` 布尔值协调追加写入、搜索范围、删除保护与摘要时机；执行结果由消息证据说明。列表、工具输出和摘要输入呈现记录内容，不附加 Run 状态分类。

摘要读取已落库的本轮消息，不复制父会话的系统指令或完整上下文。选择尾部证据、明确标记省略、排除思考内容，用模型生成短导航摘要。消息中的错误、中断和未完成事项照实保留；保存记录与生成摘要均不证明任务成功。

磁盘沿用现有 schema：`status` 列的 `running` 编码录制中，`completed` 编码停止录制，其余历史值按已停止读取。打开已有库保持历史行、摘要与消息不变；兼容原因见 [Evolution](../README-Evolution.md)。

### 成本边界

- 按完整消息落库，存储增长随实际消息量，而不是流式帧的累计快照大小。
- 启动检查当前写入者，不扫描全库消息或批量补摘要。
- 默认关键词搜索直接扫描，不增加全文或向量索引存储；正文按 Run 分段读取，每段最多扫描 250 个 Run，并返回续查入口。
- 原始 JSON 详情按字节续页；文本详情只保留最近一条的投影缓存。
- `find_run` 的 `details` 仅附带本页数量、续页标记及最多三个短标签，供调用卡片在重启后按当时结果渲染；不复制第二份完整正文，也不为显示重新查库。
- 摘要队列、输入和尝试次数有上限；每次独立模型调用主动释放传输资源。

扫描仍会完整解析单条消息，单个超大 Run 也可能超过分页的软时间目标，不是硬内存/时延隔离。批量删除是同步事务，规模样本中的耗时见[验证记录](verification.md)；当前选择明确授权时承担这笔成本，避免启动时维护。

## 与 pi-note 的分工

pi-note 独立管理用户指定的笔记目录及默认记忆入口：暴露根目录全部笔记，front matter 的 `description` 提供简介，`open: true` 默认展开正文，`open: false` 默认只展示入口；详情通过已有 `read` 工具读取。

笔记可用普通文本引用 Run；笔记组织和默认入口由 pi-note 与使用者管理，Run 积累和查阅不依赖笔记。本项目没有实现或安装 pi-note。

已确认的取舍及其由来见 [README Evolution](../README-Evolution.md)。
