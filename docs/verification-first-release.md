首版的录制、后台摘要、三个工具和 Pi 终端阅读入口可试用。`npm run check` 通过，包含类型检查、28 项自动化测试、构建和 Biome 检查。真实模型调用验证了记录→摘要→读取；终端实际走通列表→Run→消息详情。

## 自动化覆盖

入口：`npm run check`。单独运行测试为 `npm test`；SDK 场景运行真实 Pi 生命周期与工具包装层，但模型回复由本地 fixture 提供，不是联网模型验收。

- 录制：工具往返、自动重试、steering/follow-up、取消、重载、分支隔离、录制失败请求停止。
- 读取：摘要/全文/目录/时间检索、关键词排除范围、Run 与消息分页、Unicode 无损拼接。
- 摘要：本轮证据边界、异步结果归属、一次重试、队列上限、取消和独立连接释放、删除后不复活。
- 恢复：真实子进程 SIGKILL，分别在原会话与另一会话挂接后保留已提交消息，将未知结束显式标出。
- 终止工具：真实 SDK 中工具直接结束时标为 completed，工具阶段取消时标为 interrupted，两种情况都生成摘要。

### 实跑的拒绝清单

| 故意破坏的输入/状态 | 实际结果 |
| --- | --- |
| 删除批次混入活动或不存在的 Run、空批次、空原因 | 整批拒绝，原有 Run 不变 |
| SQLite 删除触发器故意中途报错 | 消息、Run 和墓碑事务回滚 |
| 模型传入错误类型的删除参数 | Pi schema 层拒绝，无删除副作用 |
| 带旧版/外来 schema 的版本 0、5 数据库样本 | 打开失败，文件哈希和 journal mode 不变 |
| 同一会话已有存活写入者 | 第二个写入者被拒绝 |
| 伪造、改查询或跨扩展实例的游标 | 拒绝并要求重新查询 |
| 非法日期、反向时间范围、非法页大小、ID 与筛选混用 | 拒绝查询 |
| 空白、超长、未结束或试图调用工具的摘要 | 拒绝保存；最多重试一次，不执行工具 |
| 终止工具没有结果、结果 ID 不匹配或未明确终止 | 保持 recovery_required，不伪造结束时间 |
| 绕过数据库约束写入坏 JSON、null、无 role 的消息 | 搜索/文本读取明确报出消息 ID；raw 保留原字节 |
| 终端控制序列与极窄面板 | 控制序列被清除，行列不越界 |

## 规模与成本

入口：`node test/benchmark.ts`，合成隔离库，不写正式归档、不调用模型。

| 样本/操作 | 本机观测 |
| --- | --- |
| 1,000 Run、25,000 消息 | SQLite 239,529,984 字节；写入约 8.17 秒 |
| 全库无命中正文查询 | 4 页，约 440 ms；单页最大约 113 ms |
| 最早 Run 的稀有关键词 | 4 页找到 1 个 Run，约 380 ms |
| 打开已有数据库 | 约 0.41 ms，仅打开，不代表完整 Pi 启动 |
| 删除 200 个 Run | 约 2.22 秒；完整性检查通过、外键错误为空 |

以上基准在新增损坏消息诊断前执行。最终解析器再以只读方式扫描同一基准删除后剩余的 800 Run / 20,000 消息：4 页、约 355 ms，单页最大约 113 ms；数据库读取前后哈希相同。未重复写入整份规模样本。

这些是本机合成数据观测，不是性能保证。同步批量删除会短时阻塞，单个超大 Run/消息的扫描没有硬时延隔离；当前未引入向量/全文索引或自主维护。
